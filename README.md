# Cybersecurity-Week-2-Labs
Cybersecurity internship practicals covering OSINT footprinting with TheHarvester and network scanning with Zenmap.

## Overview

This repository contains my Week 2 practical activities completed as part of my Cybersecurity and Ethical Hacking internship.

The practical work focused on two main areas: OSINT footprinting using TheHarvester and network scanning using Zenmap.

## Activities Performed

### 1. Footprinting and Reconnaissance Using TheHarvester

Used TheHarvester in Kali Linux to gather publicly available information related to the target domain `microsoft.com`.

Tasks completed:

- Searched for email addresses and subdomains using Baidu.
- Set the search result limit to 1000.
- Performed another search using all supported sources.
- Set the search result limit to 50.
- Reviewed the collected reconnaissance information.

### 2. Network Scanning Using Zenmap

Used Zenmap, the graphical interface for Nmap, to discover active devices on my local network.

Tasks completed:

- Identified the local IP address and subnet using Windows `ipconfig`.
- Performed a Ping Scan on the local subnet.
- Discovered five live hosts.
- Identified available IP and MAC address information.
- Generated and saved a network topology diagram in PDF format.
